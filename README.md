- 상품 데이터: `data/products.json` / 상품 이미지: `images/products/`
- 블로그 최근 글: 매일 오전 7시쯤 자동 갱신 (`.github/workflows/update-posts.yml`)
- 카테고리 목록과 문구: `index.html` 안의 `CATEGORIES`
